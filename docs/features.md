# Features

Airwave Wallet App is a non-custodial Solana wallet app (separate from the Chrome extension).

**0.1.0** is roadmap **draft** — nothing shipped yet.

**Planned MVP:** import burner wallet; wallet home with wallet widget; Assets and Activity tabs with no content yet; dApp can connect.
