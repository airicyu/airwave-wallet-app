# Features

Airwave Wallet App is a non-custodial Solana wallet app (separate from the Chrome extension).

**0.1.0** (shipped): set an app password, then generate a burner wallet; wallet home with a wallet widget; Assets and Activity tabs with no content yet; MWA connect and sign.
