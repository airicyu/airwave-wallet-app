Designer notes — not shipped UI

Ship: Logo 列、語系三選一、Next。

Do not ship: 旁注文字。

  • Mobile: 全螢幕 onboarding；語系選中態用 accent 邊框。

Ship: 鎖定密碼雙欄 +「開始」。

Do not ship: 真實密碼；稿內僅遮罩。

Ship: 對齊 web 0.52.0 rpcGuide.heliusLink：向 Helius 申請 RPC endpoint（勿寫「免費」／申請 API key）；可點 https://www.helius.dev/；略過｜設定 RPC。

Do not ship: 真實 RPC URL／API key。

  • Mobile: 首次 Mainnet 關鍵引導；與 Settings → RPC 銜接。

Ship: 帳戶 pill（主切換器）、資產列、底 tab 資產｜活動、refresh。

  • Mobile: 帳戶 pill 為頂部主導航；底 tab 保留 web IA。
  • USD 右對齊；綠盾在 token icon 左邊（對齊 web）。不可放名稱旁——防 scam 把 shield emoji 塞進 symbol／名稱偽造 verified。
  • Icons: chrome 用 web StrokeIcon.tsx 路徑；綠盾用 TokenTrust SVG（check #0f1419）；token 用 Jupiter／token-list PNG（icons/），非手畫字母圓。

Ship: combined pill、多 token；展開對齊 web HomeTokenList：row-expand-btn（方鈕＋chevron，收合 -90°／展開 0°）、member 列為短地址＋％＋數量＋accent bar（非帳戶名＋金額橫列）。

  • Mobile: 聚合展開為核心交互；收回鈕可帶 count badge（web close-empty-badge）。

Ship: 交易／送出／互換／收到列 + 時間 + explorer 外連。

  • Mobile: 列表密度可略鬆於 popup；類型色（綠入／紅出）保留。

Ship: 全寬 top sheet + scrim；7 項順序與 web 一致；觸發鈕為 web IconMenu（kebab），非三橫線 hamburger。

Do not ship: popup 下拉菜單像素布局。

  • Mobile: Back 只關 sheet。Devnet banner 留在 Home 底層可見。

Ship: ←、代幣名、hero 數量、送出 CTA、原生標記。

Do not ship: 獨立收款頁——Receive 走 Home 帳戶 pill 複製公鑰（與 web 一致）。

  • Mobile: 次要面必有 Back ≥44dp。

Ship: 餘額大字、數量 + 50%｜全部、收款地址、確認。

  • Mobile: 百分比 chips 與地址簿入口是核心適配。

Ship: 錢包｜地址簿 tabs、聯絡人列（如 Bob）。

Ship: 使用中徽章、簽名／唯讀／聚合圖示；列上重新命名、聚合的切換主錢包、kebab→管理。

Do not ship: 完整公鑰；稿用截斷。

Ship: 對齊 web 0.52.0：五列 icon＋標題＋一行副標（pin／flame／download／eye／layers）。各列進入對應子頁（見左側 Accounts 群組）。

Do not ship: 畫面內實作備註。

Ship: 與 web add-combined 同布局：名稱、主錢包卡、成員（圓點選主／grip／trash／+）、建立 CTA。左側另有 add-combined 入口。

Ship: Devnet／Mainnet 單選卡。

Do not ship: RPC URL（在 Settings → RPC）。

Ship: hub 列對齊 web 0.57.0：預設 CU 單價之下是預設優先費（新安裝 5000 lamports），再來錢包鎖定設定、Debug mode 設定。

Do not ship: API key 明文。

  • Mobile: hub IA 為手機捷徑；web 亦有 settings hub 列。

Ship: Debug mode 總開關（產品預設關）；開啟後才顯示 Jupiter API URL、OpenRouter base URL、Mainnet blockhash RPC。空值＝內建 origin。關閉時忽略覆寫。

Do not ship: 真實 vendor URL／金鑰；畫面內「與 web 一致」類備註。

  • Mobile: 稿展示開啟態以露出 URL 欄；hub summary 用「啟用」對應該態。

Ship: 站點↔帳戶視覺連線、拒絕｜連線 sticky。

  • Mobile: 全螢幕／large sheet，非窄 popup。

Ship: AI 為 web 同款單列卡（bot＋「AI 分析」＋風險指數＋藍圓報告鈕；報告開 overlay，卡內不展開）。預期變動、交易費、拒絕｜批准 sticky。

  • Mobile: full-screen approval；綠＋／紅− deltas。

Ship: v1 費卡兩欄是 CU limit 與優先費（lamports），沒有 CU price。Legacy／v0 仍是 CU limit ＋ CU price（見簽署交易主畫面的交易費列）。套用只改 config。

Ship: 失敗詳情用 disclosure marker，展開區最高 320px，摘要列有複製。批准仍可用。AI 低風險可並存。

Do not ship: 隱瞞模擬失敗。

Ship: 錢包在 Devnet 時，帳戶列下有 Devnet 細條。blockhash 只在另一個網路仍有效時顯示「網路不符」，批准停用，拒絕可用。Mainnet 錢包沒有細條，文案改成錢包目前是 Mainnet。

Ship: 與可讀 signMessage 同一殼。標題「簽署訊息」。一張 Message payload，最多九行再捲動。Off-chain 與 raw message 畫面相同，沒有格式切換。

Ship: 標題「登入」。同一張卡顯示錢包組好的 SIWS 原文；沒送的欄位整行不出現。useOffchainMessage 不改變這個畫面。

Ship: 收回額、帳戶／交易數、手續費拆分、確認。Home 收回 icon 用 web 綠 #3ddc84（close-empty-btn.active）。
